# By-Xin.github.io

Personal homepage for <https://by-xin.github.io>.

This site is built with Astro and deployed to GitHub Pages. The separate
BYNotes Quartz site remains at <https://by-xin.github.io/BYNotes/>.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

GitHub Pages deployment is handled by `.github/workflows/deploy.yml`.
